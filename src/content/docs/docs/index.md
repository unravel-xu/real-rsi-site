real-rsi 是一个研究系统工作台。System 定义 Module 组成、接口、数据连接和 Workflow。你可以在 Panel 审阅设计，发布一个版本，再为实验选择实现、资源和运行参数。

## 开始使用

- [导入 System 设计](./import/) 说明如何把市场下载的 ZIP 或 JSON 打开为可编辑草稿。
- [GSM8K 示例](./gsm8k/) 用 Prompt 自改进流程展示四个 Module 如何配合。
- [贡献一份配置](./contribute/) 介绍如何导出设计并通过 GitHub PR 提交。

## 文档与配置

在[配置市场](../market/)可以按名称、作者和标签搜索。每个条目都提供版本下载和对应的使用说明。导入需要访问你自己的 real-rsi Panel。
